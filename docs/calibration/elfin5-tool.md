# Elfin5-Pro tool calibration

仿真模型使用以下 HRIF 工具参数作为当前标定基线：

- TCP 位置：`[57.557, -25.778, 233.020] mm`
- TCP RPY：`[172.091, -46.203, 173.622] deg`
- 工具质量：`0.216 kg`
- 工具质心：`[86.831, -72.975, 285.956] mm`

这些参数以机器人末端法兰坐标系为基准。Elfin URDF 的 link6 原点到法兰面还有 `[0, 0, 156.5] mm` 固定变换，因此 MJCF 中 TCP 的 link6 局部位置为 `[57.557, -25.778, 389.520] mm`，质心位置为 `[86.831, -72.975, 442.456] mm`。RPY 按 HRIF 常用的 `Rz @ Ry @ Rx` 组合转换，MJCF 和数据层统一保存 `wxyz` 四元数，结果为 `[-0.387292070, 0.078064102, 0.914695023, 0.085110886]`。代码内部位置统一使用米、角度统一使用弧度。

机器人本体使用 Elfin5 URDF 提供的真实 mesh、质量和惯量；MuJoCo 场景使用独立的简化碰撞代理，避免直接使用高面数 STL 进行接触计算。工具惯量因缺少厂商测量值而使用保守占位值。接入真机前仍须用 HRIF 当前配置和实测 TCP 定位结果复核坐标变换、质心与惯量。

## Tool appearance approximation

原始模型附带的 Fronius 弯枪与当前实物差异较大，因此运行场景不再加载该弯枪 mesh。当前模型依据 YB1644 枪头弯管和真机照片构建：弯管组件约 `160 mm`、安装法兰厚 `20 mm`，最末端焊丝直径 `0.5 mm`。安装法兰位于 link6 的标称 `z=156.5 mm` 端面，连接器和第一段黑管严格从法兰中心轴伸出；焊丝终点严格落在上述 TCP 位置。

法兰、黑色弯管、套筒、喷嘴和最后一段 `0.5 mm` 焊丝都参与 MuJoCo 接触检测。角焊缝参考线位于水平板顶面与竖板外表面之外，并由 `task.tcp_clearance_m` 保留默认 `1.5 mm` TCP 安全间隙，不再落入竖板碰撞体内部。每个 episode 的 `collision_pairs` 会记录具体接触双方，便于区分枪体、机器人连杆和工件碰撞。

TCP 标定正确时，焊枪外形误差不会改变机器人运动学标签，但会造成腕部图像遮挡、枪尖定位和材质纹理方面的视觉域差异。当前模型适合验证数据链路，正式训练仍应加入外观随机化并使用真实数据微调。获得焊枪尺寸或多角度照片后，应直接更新 `elfin5_welding.xml` 中的分段工具几何。
