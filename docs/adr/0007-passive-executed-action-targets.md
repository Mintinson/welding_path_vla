# ADR 0007：被动采集使用下一时刻实测 TCP 作为动作标签

状态：已接受并实现（2026-10-18）；待实机验收。

真机采集端只读取机械臂状态和双相机图像，运动由外部程序、示教器或人工拖动产生，因此不能依赖外部目标命令构造监督。每条训练样本将时刻 t 的观测与时刻 t+1 实测 TCP 的世界系绝对位姿配对。

动作沿用现有 `[x, y, z, rotation_6d_rows]` 9D 存储定义，训练时复用以预测时刻 TCP 为共同锚点的 relative action 转换；这与现有 `action_targets(..., source="executed")` 的时序一致。无需迁移旧仓库的逐帧 delta 动作格式。

实测动作目标与仿真的 `safe_command` 或 `reference` 目标来源不同；字段和表示一致不代表控制语义相同，数据元信息需要明确记录标签来自下一时刻实测状态。
