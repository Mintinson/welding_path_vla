# ADR 0010：统一使用一个 Pixi 默认环境

状态：已接受（2026-11-11），替代 ADR 0001。

## 背景

按用途拆分的环境增加了命令选择和依赖安装的成本，清理共享缓存后还可能重复下载大型 GPU 包。
本机需要同时完成仿真、真机采集、训练与部署，统一依赖可以减少环境切换和维护负担。

## 决策

移除用途 feature 和命名环境，将所有依赖汇总到默认环境 `.pixi/envs/default`。
沿用训练链路的 PyTorch 2.11、TorchVision 0.26 和 TorchCodec 0.11.1，移除 CPU 专用依赖。
LeRobot 保持 0.6.0，合并数据、可视化、原生命令和已有策略所需的 extras。
日常统一使用 `pixi install`、`pixi shell` 和 `pixi run TASK`，CI 与类型检查也使用默认环境。

## 后果

新安装只维护一套完整依赖，默认环境包含 GPU 运行库，首次准备比原来的 CPU 默认环境更大。
迁移时不自动删除旧命名环境，验证默认环境后可按需删除旧目录；历史验收报告保留原始命令。
服务器仍按自身约束选择运行方式，不同步本机 `.pixi/` 目录。
