# 2026-10-20 每回合显示启动告警实测

使用真实机械臂、DECXIN global / LRCP wrist、640×480、30 FPS，在已有 Pixi dev 环境测试。
所有数据保存在独立 `outputs/validation/display_start_20261020/` 目录，标记 test_only，
不假定方向，不修改正式配置或旧数据。每组均为 3 个 3 秒回合，回合间重置 0.5 秒。

## 复现与计时

先直接运行现有 `record-real --display_data=true`，不增加计时包装。
回合 0、1 开头分别出现 20.3 Hz / 27.6 Hz 告警，回合 2 没有出现。
因此它会在后续回合重复出现，但是否越过 33.3 ms 阈值仍取决于当次调度。
它不是只发生在整个程序第一次显示的布局初始化。

随后以临时运行时包装记录原生阶段的墙钟耗时，采集/保存仍使用原生循环，
没有修改安装文件。计时仅在内存累积，退出后写 JSON。

| 方案 | 回合 0 首帧 | 回合 1 首帧 | 回合 2 首帧 | 慢周期告警 |
|---|---:|---:|---:|---:|
| AV1 流式 + 显示 | 52.501 ms | 38.052 ms | 44.177 ms | 3 |
| AV1 流式，不显示 | 4.750 ms | 4.954 ms | 11.468 ms | 0 |
| H.264 NVENC 流式 + 显示，仅诊断对照 | 314.945 ms | 231.233 ms | 213.397 ms | 3 |
| AV1 回合结束后编码 + 显示 | 8.783 ms | 6.370 ms | 5.027 ms | 0 |

AV1 流式 + 显示时，可视化首帧调用分别占 47.458 / 33.239 / 31.488 ms，
稳定后约 2.8–3.3 ms。SDK 读取和图像快照仍约 3 ms。
Rerun 布局在整个会话仅创建一次：后两回合布局检查约 0.002 ms，
不能解释它们的首帧超时。视频线程创建本身也仅约 1 ms。

## 根因：首帧惰性打开编码器时持有 GIL

原生 `DatasetWriter.add_frame()` 在每个回合第一帧启动新的编码线程。
`_CameraEncoderThread.run()` 收到第一张真实图像后才创建输出流；第一次 encode 又会
惰性打开底层编码器。因此每个回合都会再次承担初始化开销。

本机 PyAV 15.1.0 的 `CodecContext.open()` 直接调用 `avcodec_open2`，
这一段没有释放 GIL；参见[对应版本源码](https://github.com/PyAV-Org/PyAV/blob/v15.1.0/av/codec/context.pyx#L185-L205)。
正常的帧编码调用有释放 GIL 的代码，但不能据此认为初始化也会释放。
后台编码线程初始化时会暂时阻止主线程继续执行 Python，可视化调用的墙钟耗时包含这段等待。
NVENC 对照中，可视化主线程自身只消耗约 3–5 ms CPU，却等待了约 200–300 ms。

最小验证只打开编码上下文，不连接机械臂、不写视频；另一个 Python 线程每 1 ms 记录一次心跳：

| 编码器 | open 墙钟耗时 | open 线程 CPU 耗时 | 心跳中位间隔 | 心跳最大停顿 |
|---|---:|---:|---:|---:|
| AV1 / libsvtav1 | 19.214 ms | 19.051 ms | 1.092 ms | 20.206 ms |
| H.264 NVENC | 244.956 ms | 219.149 ms | 1.117 ms | 245.413 ms |

没有显示时，主线程通常已经进入等待阶段，因此未必触发按循环计算耗时判断的 warning，
但采样日志中仍能看到约 34.9–38.0 ms 的起点间隔。没有 warning 不等同于完全没有启动抖动。

## 已验证的原生处理选项

保留 `display_data=true` 和 AV1，将 `dataset.streaming_encoding=false`，
录制时暂存图像、回合结束后编码。三个回合均没有慢周期告警，
每路最终视频全部 270 帧成功解码，仍为 AV1、640×480、30 FPS。
保存的完整 video info 与服务器参考集逐项一致，schema 校验通过。
代价是临时图片占磁盘，回合保存阶段需要等待编码。

该参数目前只用于独立诊断数据，正式配置仍保持原有 AV1 流式编码。
如果继续保留流式编码，后续处理应针对每回合编码器初始化，
将其完成时刻安排在有效采样开始之前，不能只处理 Rerun 布局初始化或隐藏 warning。
